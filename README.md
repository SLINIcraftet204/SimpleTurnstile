# Simple Turnstile

Simple Turnstile adds Cloudflare Turnstile as a captcha integration for Shopware 6.

## Compatibility

Initial target:

- Shopware 6.7.9.1
- Shopware 6.7.9.0
- Shopware 6.7.8.2
- Shopware 6.7.9.1
- Shopware 6.7.x

## Features

Planned for first Release:

- Cloudflare Turnstile captcha integration
- Site Key and Secret Key configuration
- Theme selection: auto, light, dark
- Size selection: normal, compact, flexible
- Language selection: auto, German, English
- Optional remote IP transmission
- Optional debug logging
- German and English snippets
- Existing Shopware captcha configuration will be extended, not overwritten
